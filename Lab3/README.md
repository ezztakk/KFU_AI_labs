## Лабораторная работа №3: Метрики качества, кросс-валидация и пайплайны
# 1. Описание проекта
Применение математического аппарата метрик качества и строгой методологии тестирования ML-моделей. Сбор индустриальные конвейеры (Pipeline) для предотвращения утечки данных (Data Leakage) и автоматизировать подбор гиперпараметров с помощью алгоритмов поиска.
# Выполненные задачи

1.Был выбран датасет "Telco Customer Churn":Прогнозирование оттока телеком-клиентов.

2. Удален неинформативный столбец CustomerID, TotalCharges преобразован в числовой тип, целевая переменная переведена в бинарный формат, выявлен дисбаланс классов

3. масштабирование числовых признаков через StandartScaler и категоральных через One-Hot Encoding. Лучшее количество соседей = 9

4. модель лучше предсказывает оставшихся клиентов, с уходящими больше ошибок. ROC-AUC: 0.8129

5. определены лучшие параметры - 9 ближайших соседей с равной важностью значений

6. модель показала MAE (Средняя ошибка) 858.27 и SMAPE (ошибка в %) 44.64%, что значит что она неточна (большой процент ошибок) и плохо себя проявляет для прогнозирования точных платежей

7. данные визуализированы с помощью графиков, по ним можно сделать вывод что модель не подходит для предсказаний, так как недостаточно точно прогнозирует данные


Ошибки первого рода ведут к разовым расходам, тогда как ошибки второго рода влекут за собой потери прибыли (т.к. клиенты ушли)
