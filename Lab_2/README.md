# Лабораторная работа №2: Метод k-ближайших соседей и непараметрические методы регрессии

## Описание проекта

Применение непараметрических алгоритмов машинного обучения (kNN и Ядерная регрессия Надарая-Ватсона)
и изучение влияния метрик расстояния и гиперпараметров на качество прогнозирования реальных экономических показателей.

##  Выбор датасета

Предсказание рыночной стоимости автомобилей с пробегом
Был выбран датасет Used Car Price Prediction - [https://www.kaggle.com/datasets/therohithanand/used-car-price-prediction](https://www.kaggle.com/datasets/ayaz11/used-car-price-prediction/data)

## Задачи:
1. Загрузка и Разведочный анализ (EDA): загрузка данных, их очистка и группировка по категориальным признакам;
2. Подготовка признаков перевод категориальных в числа, разбиение выборки и масштабирование числовых признаков;
3. Поиск оптимального числа соседей (k) перебором нечетных значений от 1 до 25 с сохранением MAE для каждого k;
4. Сравнение метрик расстояния Минковского: обучение моделей на Евклидовом расстоянии и Манхэттенском, сравнение метрик;
5. Ядерная регрессия Надарая-Ватсона: реализация метода с использованием Гауссовского ядра, поиск лучшего gamma;
6. Визуализация через Scatter-график и составление бизнес-вывода по результатам.

## Финальный бизнес-вывод
модель подходит для автоматической оценки автомобилей массового сегмента 0–40.000$ например, при трейд-ине, страховании или размещении объявлений. Для премиум-сегмента модель не подойдет, т.к. будет занижать цену машин
